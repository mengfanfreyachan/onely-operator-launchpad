# 72 小时，100 位美国社媒运营者：增长与入驻方案

这是一套待执行的招募方案。数据规模、转化率与费用为假设；没有真实招募结果。目标人群不是美国居民，而是有能力为美国创作者运营社媒、维护粉丝关系的人，包括菲律宾、尼日利亚及其他地区。

## 1. 业务理解与招募承诺

2026-10-24 阅读 Onely 官网：其定位为 AI-powered creator business platform，连接 identity → content → social distribution → fan relationships → subscriptions / e-commerce，面向 creators、agencies、operators、brands，处于 private beta。官网展示社媒发布、粉丝关系层、1:1 Fan Access 和 Agency Console，但页面描述不等于 API 开放或试点容量已经确认。

本方案按照题目指定的“首期情感陪伴业务”设计：运营者负责美国受众理解、内容分发、粉丝互动质量和关系维护；AI 辅助重复内容、文案与关系工作。不能把“情感陪伴”简单改写为泛泛招聘 SMM，也不能默认所有普通 SMM 都愿意做粉丝互动。

**最小岗位说明：** 明确陪伴 / 粉丝互动工作是什么、是否涉及虚拟身份及如何披露、哪些内容不做、工作时间、首任务、报酬模式、结算日、退出机制和支持渠道。不得承诺“轻松收入”“保证变现”；不得要求候选人支付入职费。若试点不是雇佣，而是平台经营合作，需在标题与合同中如实说明，避免以有薪岗位吸引到只有分成的合作。

正式首触达文案：

> Hi [first name], your profile mentions managing [platform] for [market] audiences. Onely is an AI-powered creator business platform, and this founding-operator pilot focuses on US social growth and emotional-companionship fan experiences. Operators retain responsibility for tone, boundaries and quality; AI supports repetitive workflows. Would you like the role brief and a short skills assessment? We will explain workload, compensation, payment timing and pilot access before you commit. If this is not relevant, reply “no” and we will stop following up.

发送前将 assignment 字样改为经授权的招聘主体，填入已确认的岗位说明链接。上述模板不是已发送邮件。

## 2. 成功定义与必要条件

**一名“入驻完成”人员：** 唯一身份；18+；美国社媒运营能力核验通过；英文及实操 ≥75/100；接受真实工作与补偿条款；获得平台访问；培训通过；首任务审核通过并记录账号 ID。

不同口径分开汇报：source / contacted / positive reply / applied / qualified / accepted / activated。进群人数不计入 100 人，重复账号不重复计数。停止联系的人继续保留历史漏斗记录。

在 H0 前确保：

- Onely 或组织方能在 72h 内提供至少 120 个真实试点席位和账号准入。
- 岗位 / 合作条件已经书面确定，候选人能使用实际结算方式，无须垫付入职资金。
- 有品牌授权的发件身份与现成信誉渠道；新邮箱域名不能靠一天“预热”支撑大量冷邮件。
- 4 人团队可投入约 72 个招募工时、42 个审核工时、12 个培训工时，共 126h；渠道已经存在或能快速取得管理员同意。
- 公开岗位说明、报名表、邀请条款与实操题已准备，机构 / 社群合作可兑现。

若完全从零、没有渠道信任和支付承诺，三天保证 100 位合格人员不可信。此时将任务拆为首日验证与条件式扩量；不通过门槛就重估期限和目标。

## 4. AI 如何找到和筛选合适人员

**资料获取工作流：** 检索词扩展 → 按许可读取岗位 / 自愿报名资料 → 提取运营平台、市场、时长、任务、证据 URL、可用时段 → email / profile 去重 → AI 信号 + 规则预筛选 → 人工能力验证。

生产版使用 AI 将非结构化简介提取为 JSON，每个字段附原文证据和“自述 / 验证”标记；无法支持的字段保持空值。不要让模型推测英语水平、美国客户经验或所在地。当前原型实现的是结构化资料导入 + 本地轻量经验分类；自动资料获取与 LLM 证据提取未实现。

**优先级评分**沿用 README 中 100 分表。A 是优先联系，B 是补证据 / 可转型，C 是暂缓。地域只用于渠道与排班，最终美国能力标准相同。

**必须人工验证的能力：**

1. **操作权与实绩：** 一份经授权、可脱敏的账号管理记录或作品证据，解释本人贡献、时间、目标受众、触达 / engagement / 点击或其他指标。禁止索取客户密码，不能仅凭“熟悉 TikTok”通过。
2. **美国语境：** 为给定美国虚拟创作者写 3 条 IG / TikTok hook；解释发布时间、用户意图、评论回应。没有美国客户实绩者需通过美国账号拆解作为替代证据。
3. **情感互动与边界：** 对孤独、反复催回复、过度依赖等 3 个场景写英文回复。语气温暖但不制造虚假关系、不冒充真人承诺，不将严重情绪困扰当作强推付费机会；超出能力的情况交人工支持。
4. **转化能力：** 将内容 → 合法、真实的 creator page → 可选择的互动 / 订阅连接成路径，说明透明身份和用户退出机制。
5. **稳定执行：** 每周 ≥10h、能参加培训、可靠设备 / 网络；按自选当地时段排班，不要求所有人长期熬夜配合美国时区。

**30 分钟测评评分：** 美国内容与语境 30、英文互动质量 25、粉丝边界 / 身份披露 20、数据与转化判断 15、执行与协作 10。总分 ≥75，且边界项 ≥15、严重冒充 / 骚扰 / 无视停止请求者不通过。原型记录总分与确认项；细分测评表、语音面试和证据附件管理尚未实现。建议把提审量拆为 4 个审核批次，边界争议由主审核员复核。

这些是**条件概率假设，未经验证**。成功首触达指站内发送成功 / 有效送达或本人参与，而不是生成了文案；公开演示用操作员事件代替真实 webhook，不能证明投递。实际工作汇报要把 generated / reviewed / sent / delivered / replied 分开。

200 人试跑时采用渠道分层随机 A/B，每层各分 50% A 和 B，分别以“你已有的经验关联”“减少重复运营成本”开场；唯一主指标为 24h 内积极回复率，次指标为实操通过与激活成本。每人只进入一个版本，记录来源、版本、发送时刻；样本不足不宣称统计显著胜者。原型支持 A/B 文案和版本字段，未实现随机分配和完整实验报告。

**敏感性：** 积极回复从40%降到20%，其他条件不变，期望激活为51.408。要维持100，理论需约3,112.36条原始记录；向上取整至少3,113。不能只靠翻倍私信解决信任和人力问题；优先找温热推荐、提高岗位透明度、延长期限。

**每源指标：** 唯一有效人员数、审核通过 / 联系人数、激活人数、花费 / 激活人数；后续看质量和 D7。机构 / 群贴 / referral 都带 source code，保留原始来源。所有活动先去重，不对同人跨渠道重复轰炸。

## 6. 72h 执行安排与分工

|时段|负责人 / 行动|累计目标与决策|
|---|---|---|
|0–4h|增长负责人确认角色与补偿、报名表、测评；AI 整理公开资料与检索词；工程 / 自动化配置字段|前置条件失败则不开始大规模招募|
|4–12h|2 名招募人员接洽40个机构 / 12位管理员；按平台许可手动筛选首批200人|拿到合作回复和首批有效申请；记录真实渠道容量|
|12–24h|200人分层A/B试跑；首场简短介绍与Q&A；建立问答库；审核员滚动实操|原始600、累计首触达300为计划；积极回复<20%或伙伴无响应时重估目标|
|24–36h|复制较优渠道，优先A+B；第一批实操审核；处理24h一次跟进|不抬高评分来追人数；资格不过不激活|
|36–48h|第二轮补充；两场课程 / 答疑；把已通过者分组|原始累计1,200、首触达650；积极回复累计不足200时启用温热推荐备用池|
|48–60h|停止扩散低效冷渠道；滚动发真实邀请、培训、审核首任务|151人能力通过是目标，100人激活仍依赖席位与支付条件|
|60–72h|增长负责人核对100个唯一账号；培训负责人完成首任务；统计实际漏斗 / 未完成原因|原始1,600、首触达900；申请252、通过约151、接受约120、激活期望102|

**最小4人配置：** 增长负责人（伙伴、条件、异常与QA）；招募A（菲律宾、社群、平台）；招募B（尼日利亚、机构、推荐）；审核 / 培训负责人。前3人轮流参与审核，分担42h核验；约126h / 4 =31.5h每人、3天约10.5h/天，是冲刺强度，不是长期排班建议。若只有1人，需要缩小目标或延长时间。

**接触节奏：** 每个招募人员每天首触达约150人，合计900；若每次审稿加站内发送约1.5min，约22.5h，两人合计可承载。其余时间用于对话 / 伙伴；任务审核另计42h，不能隐藏在人力模型里。未获得平台额度或许可时，降低直接联系人数，利用获准岗位帖子与自愿报名替代，不能开多个账号规避限制。

## 7. 入驻、批量培训与留存

**主阵地选 Discord，Telegram 可选通知，表单 / CRM 是身份与进度记录。** 根据当地偏好选择入口，不要求同时安装三个工具。Telegram Bot 只能给主动启动过会话且同意通知的人发送更新。平台招募者只有在平台规则允许后才转入外部协作。

Discord 结构：

- `#start-here`：岗位 / 合作说明、真实补偿与结算、身份披露、工作边界、步骤清单、退出方式。
- `#announcements`：只读；固定培训时间与系统通知。
- `#training-library`：四个10–15分钟模块，产品 / 角色、美国内容、互动边界、数据记录；测验后解锁。
- `#cohort-01…04`：100 人分4组、每组25人，由4位负责人分别答疑；每组最多一个共同任务帖，避免100个私聊。
- `#help-desk`：FAQ优先、必要时工单；AI从已审核FAQ检索答案，低置信度转人工，不自由承诺付款与收入。
- `#wins-and-feedback`：高质量匿名案例、成员反馈和推荐；不公开客户私人对话或敏感账户数据。

角色：Applicant → Verified → Trainee → Active Operator → Mentor；仅经审核者可进入工作频道。真实 Bot 应根据CRM事件赋角色 / 课程，而不是看到“加入群”就发 Active。当前原型只展示并记录清单，**没有实际建群、赋角色、Bot、课程解锁或消息发送**。

培训结束后首任务：给定一个明确披露身份的US creator / persona，提交7天内容计划、3条短视频 hook、3个粉丝互动场景回复和一个基础指标表；按质量审核，严重边界问题单独辅导。试用任务有明确补偿，不把候选人作业用于未约定的商业交付。

**留存机制：** D0提供一个能完成的小任务与固定答疑；D1看任务是否完成 / 成员障碍；连续24h无任务先询问是否遇到权限、学习或时间问题；D3分享优质案例；D7回访工作量、工具问题、支付清晰度和继续合作意愿。退出者停止推送并保留必要审计记录，按真实政策处理资料。

**指标与分母：** Activation24h、培训完成、首任务通过、D1/D7合格任务留存、每人支持分钟数、成员满意度、首批工作质量。D1≥70%、D7≥50%为初始假设。72h能观察早期成员的D1，不能验证D7。观察窗未完整结束的成员不进入分母；退出者不从已经激活的成熟队列剔除。原型支持合格任务事件与成熟窗口计算，样例只是虚构历史。

## 9. 上线迭代顺序

1. **验证岗位与渠道：** 先取得真实试点授权、支付承诺与200人试跑数据。
