# 演示视频脚本

视频使用真实浏览器操作原型，约 3–5 分钟，中文系统合成语音。每段旁白和画面目的记录于 [voice.json](voice.json)。视频中所有人名、邮箱、阶段和数据为虚构；招聘预测单独标为假设。

|段落|画面|
|---|---|
|目标与业务理解|首页目标、官网映射、激活定义|
|增长漏斗与敏感性|编辑积极回复率 40→20；102→51|
|三天行动安排|72小时计划与渠道组合|
|导入与去重|导入示例CSV两次；新增6→0|
|筛选与能力门槛|人员详情、分级证据|
|个性化触达|A/B 文案、审核与联系许可|
|跟进与状态门槛|逐级推进、不能跳过核验|
|批量培训与留存|Discord 分组方案、D1/D7 指标|
|已实现与待验证|产品边界与完整文档入口|

未使用或展示真实候选人资料、真实 Token 或真实消息投递。
